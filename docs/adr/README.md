| ADR | Decision |
|---|---|
| [ADR-PAY-0001](ADR-PAY-0001%20—%20Adopt%20HyperSwitch.md) | Adopt HyperSwitch as the headless Baobab payment orchestration engine (refreshed 2026-09-25) |
